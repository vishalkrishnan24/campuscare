# CampusCare — HACKDAY 1.0
A responsive web application for reporting, prioritizing and tracking campus problems.

## Problem
Campus issues such as broken infrastructure, cleanliness problems, water issues, electrical faults and weak connectivity may be difficult to report and track systematically.

## Solution
CampusCare provides a simple issue-reporting workflow with category, location, priority, status tracking, progress indicators and a campus issue feed.

## Technology
HTML5, CSS3, JavaScript, browser LocalStorage.

## Run
Open `index.html` in a modern browser.

## Demo
Submit an issue, then use the status button to move it from Open → In Progress → Resolved.

## Future scope
Cloud database, admin dashboard, authentication, photo uploads, GPS/location tagging, notifications, analytics and AI-based issue prioritization.

## Note
This is a hackathon prototype. Data is stored locally in the browser and is not shared with campus administrators.
